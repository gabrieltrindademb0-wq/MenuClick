MenuClick - Avaliações com fotos

Estrutura para GitHub Pages:
- cliente/index.html
- restaurante/index.html
- criador/index.html

Atualizações desta versão:
- Removido o botão "Exportar meus dados" do app do cliente.
- Adicionada seção "Avaliações" no app do cliente.
- Média geral de estrelas.
- Comentários de clientes.
- Fotos nas avaliações.
- Modal profissional para avaliar pedido com estrelas, comentário e upload de fotos.
- Painel do restaurante mostra média, lista de avaliações e fotos recebidas.

Observação: as fotos são salvas localmente no navegador usando localStorage. Para produção, use armazenamento online como Google Drive, Firebase Storage ou Cloudinary e grave apenas o link no banco/planilha.
